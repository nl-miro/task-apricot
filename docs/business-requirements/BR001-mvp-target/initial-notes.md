# Initial notes


- we are building task+calendar app named apricot

Targets for MVP:
- Android mobile app + mobile web + desktop web
- in order to use our app, customer needs to register, just using email address will be enough. Login tokens will be sent via email instead of us keeping passwords
- from day one, we will include plans: alpha (limits to be decided later) + beta (limits to be decided later)
- actual billing is not part of MVP
- customer can open project
- customer can fullfill task form with title, dates , importance, project it belongs to (mandatory)
- importance options will be very,normal,low, normal being default
- dates will have few modes, values named start/after and end/before: for single day task they have same value. If task takes a week, it starts on Monday and ends on Sunday. If we need to complete it by Wednesday, only end/before will have value. If something needs to be done after Monday, only start will have value set.
- customer can fullfill calendar events using title, from datetime + to datetime,importance, project it belongs to
